# Ideas

Brainstorm notes, captured before any decision is made. Nothing here is approved,
scheduled, or specced. An idea graduates by being promoted to an item in
`ai/roadmap.md`, at which point its own `ai/features/<name>/` folder takes over
and the entry here points at it.

One file per idea, named `YYYY-MM-DD-short-name.md`, newest at the bottom of
this list. Bugs found while testing live here too, with the same rules — a fix
gets promoted the same way an idea does.

Each file opens with a **Status** line — `pending` while it is only a note,
`completed` once a roadmap item has built it, with a link to that item. Some are
captured verbatim as given, with no status line until they are specced. The
roadmap stays the single source of truth for what is next; these links only
record which item an idea became.
